# Comprehension Bench identity

The original SVG wordmark and standalone mark are in `assets/`. They use vector geometry rather than a raster image and remain editable at any resolution. The visual metaphor reflects the tool’s job: evidence for Proofpacket, linked steps for Living Explainers, branching cases for Intent Workbench, paired entries for Org Lexicon, changed lines for Meaning Diff, review for Spec Sentry, propagation for Decision Ripple, constraints for Output Contracts, and observations for Comprehension Bench.

Use `assets/logo.svg` on a light background and `assets/mark.svg` where a compact identity is needed. Brand assets follow the repository’s private, all-rights-reserved license. No affiliation with another project is implied.
