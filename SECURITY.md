# Security

Do not file public issues containing private documents, credentials, or participant data.
Use the repository owner's private GitHub contact channel to report a vulnerability.
Include the affected revision, reproduction steps using synthetic data, and likely impact.

The intended workflow is local. Source documents and models are untrusted data, not
instructions. Inspect generated reports before sharing them. A source reference, passing
check, or heuristic finding does not establish complete correctness. Command-execution
features, where available, run only commands explicitly supplied by the operator;
never feed unreviewed document contents into them.
